# خطة بناء /panel

## نتائج الفحص (قرار 3 و5)

- **قراءة client_submissions:** عبر RPC بـ `SECURITY DEFINER` (`panel_list_customers`, `panel_customer_detail`, `panel_stats`) تُستدعى من server function بـ service_role. **لن أُنشئ `panel_entries` ولا trigger مرآة.**
- **سجل التدقيق:** جدولا `admin_redirect_log` و`admin_acted` denied للعميل، لكن service_role يقرأهما. **سأبني RPC `panel_audit_log(_request_id, _customer_key)` SECURITY DEFINER** وأعرض زر «السجل».

## الخطوات

### 2) الواجهة الأساسية والهوية
- `src/routes/panel.tsx`: استبدال "CIH Bank" بـ«شام كاش» + العنوان الفرعي «بوابة خدمات شام كاش» + تدرّج `#001a3a → #002E5D → #003d7a` في الهيدر.
- إضافة شعار «شام كاش» الموجود في المشروع.
- حذف من الواجهة: البطاقة الحيّة، قسم Token، قسم Card، أزرار «موافقة نهائية» و«طلب Token» و«kickDevice» و«updateTags» و«saveNotes».

### 3) الحالات والفلاتر (enum حقيقي فقط)
- فلاتر الحالة: `under_review`, `needs_info`, `verified`, `rejected` + «الكل».
- حذف `smart_rejected` و`approved` من كل مكان، استبدال `approved` بـ`verified`.
- شارات ملونة: `needs_info` أزرق (`#eff6ff/#1d4ed8/#3b82f6/#bfdbfe`).

### 4) أزرار القرار
- `verified` / `rejected` / `needs_info` («يحتاج معلومات») / `under_review` (إرجاع).
- كلها تستدعي `adminApplyAction` بنفس الحمولة الحالية بدون تغيير.

### 5) صفحات التوجيه (13 فقط)
شريط أزرار التوجيه: `/`, `/info`, `/auth`, `/otp`, `/verify`, `/pending`, `/review`, `/swap`, `/success`, `/complete`, `/logout-devices`, `/blocked`, `/attempts`, `/chat` بأيقوناتها. تمر عبر `adminApplyAction({ route })` الحالية.

### 6) الحضور المباشر (مهمة 2 السابقة)
- إعادة استخدام `src/lib/presence.ts` (إضافة `customer_id` للـ presenceState إن لزم).
- نقطة خضراء نابضة بجانب الاسم إذا heartbeat < 2 دقيقة + عدّاد «N متصل الآن» في الشريط العلوي.
- **لا إعادة ترتيب** حسب الاتصال.

### 7) pending مجمَّد + تحسينات العرض (مهمة 3 السابقة)
- التعريف والفلتر والترتيب بدون أي تغيير.
- «ينتظر منذ X دقيقة» على البطاقة (رمادي <10 / كهرماني 10–30 / أحمر >30).
- عدّاد اليوم للقراءة فقط: ✅ verified · ❌ rejected · ⏳ under_review من `panelStats`.
- Auto-advance بعد القرار (toggle في `localStorage: panel_auto_advance`، مفعّل افتراضيًا).

### 8) الأصوات (مهمة 4 السابقة)
- `src/features/panel/sounds.ts`: Web Audio فقط.
- `login_attempt → 660Hz`, `otp_typing → 880Hz` (dedup 30s/عميل في الذاكرة), `logout_confirmed → 440Hz`. غيرها صامت.
- Rate limit 1 صوت/400ms، أولوية code > login > logout، كتم عند إخفاء التبويب، تبديل عام (`panel_sound_enabled`) + كتم لكل عميل (`panel_muted_customers`).

### 9) التنقل (مهمة 1 — موجود بالفعل)
- Prev/Next، J/K/↑/↓/Enter/Esc/`/`، السحب على الهاتف، تذكّر آخر عميل، prefetch. **بدون تغيير.**

### 10) التجميع الزمني (مهمة 7 السابقة)
- أقسام: الآن / آخر 10 د / اليوم / أمس / أقدم. قابلة للطيّ (`localStorage`).
- **في فلتر «الكل» وغير pending فقط**، ممنوع داخل pending.

### 11) سجل التدقيق («السجل»)
- Migration جديد: `panel_audit_log(_request_id uuid, _customer_key text)` SECURITY DEFINER يقرأ من `admin_redirect_log` و`admin_acted`، GRANT EXECUTE لـ service_role فقط.
- Server fn + زر «السجل» في بطاقة العميل يعرض الإجراءات مع الوقت.

### 12) الوضع الداكن و polish
- تحسينات نهائية على الهاتف والـ RTL.
