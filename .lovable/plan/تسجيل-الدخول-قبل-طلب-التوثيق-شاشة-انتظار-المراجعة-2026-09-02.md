# تسجيل الدخول قبل طلب التوثيق + شاشة انتظار المراجعة

## الفكرة
زر «تقديم طلب توثيق جديد» لن يفتح المعالج مباشرة، بل ينقل العميل إلى صفحة تسجيل دخول. بعد الدخول ينتقل إلى صفحة «قيد المراجعة» ويبقى فيها حتى تعتمد لوحة التحكم الطلب أو ترفضه.

## تدفق المستخدم
```text
الرئيسية ── «تقديم طلب توثيق جديد» ──> /auth (بريد + كلمة مرور + زر دخول)
   └─> بعد الدخول ──> /review  (حالة الطلب: قيد المراجعة)
           ├─ الإدارة تعتمد  ──> شاشة «تم التوثيق»
           └─ الإدارة ترفض   ──> شاشة «مرفوض» مع سبب الرفض
```
العميل لا يستطيع مغادرة صفحة المراجعة إلى المعالج ما دام الطلب قيد المراجعة؛ أي محاولة فتح صفحة محمية تعيده إلى /review، وأي زائر غير مسجل يعود إلى /auth.

## الصفحات
1. **/auth** — بطاقة زجاجية بنفس هوية الموقع: البريد الإلكتروني، كلمة المرور، زر «تسجيل الدخول»، ورابط صغير «إنشاء حساب» لمن لا يملك حساباً (نفس الحقول). رسائل خطأ عربية واضحة.
2. **/review** — بطاقة حالة تعرض: رقم الطلب، البريد، شريط الحالة (قيد المراجعة / موثق / مرفوض)، ملاحظة الإدارة عند الرفض أو طلب معلومات، وزر تسجيل الخروج. تتحدث الحالة تلقائياً دون إعادة تحميل.
3. **لوحة التحكم /admin** — أزرار «اعتماد» و«رفض» تصبح فعلية وتغيّر حالة الطلب في قاعدة البيانات، فتنعكس فوراً على شاشة العميل. الجدول يعرض الطلبات الحقيقية بدل البيانات التجريبية.

## الجانب التقني
- تفعيل Lovable Cloud (قاعدة بيانات + حسابات مستخدمين) مع تفعيل الدخول المباشر بعد إنشاء الحساب دون رسالة تأكيد بريدي.
- جدول `profiles` (الاسم، البريد) مرتبط بحساب المستخدم مع إنشاء تلقائي عند التسجيل.
- جدول `verification_requests` (المستخدم، رقم الطلب، الحالة: under_review / needs_info / verified / rejected، ملاحظة الإدارة، التواريخ) — يُنشأ صف «قيد المراجعة» تلقائياً عند أول دخول للعميل.
- جدول `user_roles` منفصل + دالة `has_role` للتحقق من صلاحية المشرف؛ الاعتماد/الرفض مسموح للمشرفين فقط عبر سياسات RLS مع منح الصلاحيات (GRANT) اللازمة.
- حراسة المسارات: مجموعة `_authenticated` تعيد غير المسجلين إلى /auth؛ صفحة /review تستخدم TanStack Query مع تحديث دوري لعرض تغيّر الحالة.
- تحديث زر الهيدر/الرئيسية ليشير إلى /auth، وإظهار حالة الجلسة (دخول/خروج) في الهيدر.

## خارج النطاق
لا تغيير على تصميم الألوان أو بقية الصفحات، ولا على مراحل معالج التوثيق نفسه في هذه المرحلة.
